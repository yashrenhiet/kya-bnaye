## Smaller engineering debt (not blocking, worth doing)

- [ ] **DRY:** `scrollTo`/`scrollToTop` helpers are duplicated near-identically across
  `CriticalPathUITests.swift`, `OnboardingPantryUITests.swift`, `HomeDeckUITests.swift`.
  Extract to one shared `XCUIApplication`/`XCTestCase` extension.
- [ ] Onboarding **Back** isn't disabled while a save is in flight (needs a UI test) — L4.
- [ ] Dish-picker tile uses a hardcoded `minHeight: 88` / `.font(.title2)` instead of a
  `Theme/` token — L4.
- [ ] Decorative artwork initial contrast on light turmeric measures 2.09:1 — decorative
  element, so it's a design call whether it needs fixing — L5.
- [ ] Dismissed auto-added shopping rows are forgotten on relaunch (by design today,
  documented) — confirm this is the wanted behaviour or turn it into a product decision.
- [ ] `KyaCore/Ports/SeedSync.swift` has no tombstones: a backup import or "Reset all
  data" can bring back a seed recipe the user deleted. Recipes UI already maps delete →
  hide for seed recipes, so this only affects those two other paths — L2/L4.
